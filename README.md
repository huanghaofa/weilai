# 蔚来销售与市场研究报告

[打开在线报告](https://huanghaofa.github.io/weilai/)

报告面向行业与市场研究、竞品与营销分析，覆盖蔚来 NIO、乐道 ONVO 和萤火虫 firefly。

- 2018—2025年年度交付与2024年1月至2026年9月的33个月度交付数据。
- 14项车型价格资料、财务对照、销售渠道、补能体系、营销与竞品分析。
- 10幅交互图表及品牌构成图，75条来源索引，其中70条为一手资料。
- 支持年份与品牌筛选、BaaS现金支出演示、资料搜索以及CSV和完整研究数据导出。

## 资料时间

资料检索截止2026年10月26日。完整月度交付截至2026年9月，财务资料截至2026年第二季度；不同车型价格分别注明日期和来源性质。

## 查阅方式

`index.html` 是可独立打开的完整报告，不依赖外部图表库或字体服务。下载后可以离线查阅图表、数据和正文，打开原文链接需要联网。

集团交付、品牌交付、国内零售、批发、订单与累计里程碑采用各自口径；价格、促销及服务资料的适用条件详见报告。
